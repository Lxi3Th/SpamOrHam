# SpamOrHam
A Spam or Ham Detector is a machine learning program that uses the Multinomial Naive Bayes algorithm to classify messages as spam (unwanted or suspicious messages) or ham (legitimate messages) with a result of 95.26% accurate.

# How does it work 

A dataset gets imported and translated using ```CountVectorizer``` to count the number of same words in the sentence, then it uses this data to transform it and train the naive baye Multinominal algorithm which takes numbers as input and spits out a prediction whether the message is spam or ham

```Scikit-learn```
